# 使命（Mission）

## 愿景

让智能车竞赛电磁组的赛道磁场与循迹控制**可视、可算、可验证**：把"20 kHz / 100 mA 贴地电磁线 + 车载工字电感 + 差速循迹"这一物理过程建成完整的数学模型链条（赛道几何 → 磁场分布 → 电感响应 → 循迹控制），并提供桌面仿真工具用于赛前调参与方案验证，使仿真整定结果可移植到实车。

## 目标用户 / 受众

- 参赛学生本人（浙大宁波理工学院，智能车/电子硬件方向）——主要使用者：调参、实验标定、写竞赛/学位论文；
- 队友与指导老师——理解建模方案与实验结论；
- 评委——竞赛报告与论文的模型依据；
- 未来的自己与接手维护的 AI 智能体——靠本 specs/ 体系恢复全部决策依据。

## 范围

### 范围内（In Scope）

- 电磁赛道的准静磁场建模（毕奥-萨伐尔、直线段闭式解）与可视化（热力图/等值线）；
- 电感响应建模、布局编辑、贴线锚点标定与全程扫描；
- 循迹闭环仿真：可编辑误差公式、PD、差速轮速、电机一阶滞后、运动学积分、一键整定；
- 实测数据经验模型（方案A 拟合 / 方案B 物理+偏差）与 CSV 导入导出；
- 实验建模手册（参数标定 / 数据建模 / 偏差分析三类九项实验）与数据接口约定；
- 实车嵌入式控制代码以 WASM 形式载入仿真验证：控制器 ABI 约定（宿主导入函数 + 多速率任务入口）+ 内置公式控制器兜底（见 `specs/features/13-wasm-controller/`）；
- MATLAB/Simulink 对照移植（公式与 JS 数学模型层逐行对齐）；
- Windows 便携版 exe 打包与发布。

### 范围外（Out of Scope）

- 实车嵌入式工程本身（交叉编译链、烧录、车队仓库维护）：本项目只提供控制器 ABI 约定与 WASM 仿真宿主，验证后的控制代码仍由车队工程落地实车；
- 串口实时采集（SerialSource 为预留方向，见 roadmap Phase 11）；
- 三维 / 瞬态 / 全波电磁场仿真（准静态近似已足够，见 specs/features/02-magnetic-field/）；
- 竞赛论文正文的撰写（数学模型内容可作论文素材，但论文文档不在本体系内维护）；
- `track_model/`（Python 版）的继续演进——已完成使命，仅作结论参考保留。

## 语气与风格

- 严谨、学位论文范式：公式按节编号（式 (x.y)）、公式前有引导语、后有"其中……"符号说明、重要公式附物理意义解读；
- 简体中文行文，技术术语保留英文（如 Worker、localStorage、Vpp）；
- 状态标记约定：✅ 已实现｜🔶 设计变更（待改代码）｜⬜ 新增设计（待实现）｜🧪 约定已生效、待实车数据。

## 成功标准

- 全部自动化自检通过（`npm run selfcheck` / `selfcheck:measured` / `selfcheck:tracking`，判据见各 feature 的 validation.md）；
- 仿真与实车的偏差区间被实验量化界定（实验 8/9，Err 过零点与各电感峰值逐弯对应、量级偏差 < 30%）；
- 一键整定得到的 Kp/Kd 与整车参数（τ_m、W、v_base）经实验标定回填后可直接指导实车调参；
- 任何设计变更可沿"规约 → 代码 → 自检"追溯，文档与代码不漂移。
