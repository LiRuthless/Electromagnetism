# 参考学位论文清单（浙大 / 清华）

> 用途：为电磁赛道建模仿真项目（毕奥-萨伐尔磁场建模 → 电感读数 → 循迹控制仿真 → 实测验证）寻找流程/内容相近、格式规范的研究生学位论文作为写作参考。
> 整理时间：2026-08-12

## 说明

直接以"电磁循迹智能车"为主题的浙大/清华**研究生**学位论文基本没有（该题目属于本科竞赛范畴，知网上能查到的多为其他院校的本科毕设或期刊短文）。因此下面挑选的是**研究流程高度相似**的论文：载流导线/线圈磁场建模 → 传感器（电感/线圈）读数 → 建模仿真 → 实验验证，部分含偏移/偏差分析与控制环节，且均为格式规范的标准学位论文。

## 清华大学

| 论文 | 作者 | 学位/年份 | 相似点 |
|---|---|---|---|
| 《磁耦合谐振式无线电能传输关键技术研究》 | 张艺明（导师：赵争鸣） | 博士，约 2014 | 清华优博论文。载流线圈磁场分布计算、偏移（错位）对耦合的影响、建模仿真 + 实验验证，流程与你的"磁场建模→读数→验证"几乎一致 |
| 《基于磁场传感线圈的昆虫飞行跟踪测量系统》 | 蔡志坚 | 硕士，2005 | 用磁场传感线圈阵列检测信号并反解目标轨迹，与"电感读数 → 位置/轨迹"的思路相同，含坐标系建模与误差分析 |

## 获取方式

- 中国知网（CNKI）学位论文库，按"论文题目 + 作者"检索；学校（浙大宁波理工学院）图书馆一般已购知网学位论文库，校园网或 VPN 可直接下载 PDF/CAJ。
- 浙江大学学位论文可在浙大图书馆学位论文系统查询；清华学位论文可在清华图书馆"学位论文服务系统"（部分仅校内可读，知网有收录的优先走知网）。

## 备选（非浙大/清华，但内容几乎一模一样，可作补充参考）

- 张云洲等《基于电磁效应的轮式智能车导航控制》，东北大学学报，2013（期刊论文，含电感感应电动势公式推导）
- 蔡春山等《基于电磁寻迹的智能车仿真》，齐鲁工业大学学报，2017（电磁寻迹仿真，与循迹闭环仿真最接近）
- 竞赛秘书处《电磁组竞赛车模路径检测设计参考方案》（电磁组官方参考，含毕奥-萨伐尔推导与差比和算法）
