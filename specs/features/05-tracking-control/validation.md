## 人工验证步骤

1. **闭环仿真与防抖重算**：`npm run dev` 启动，铺设含弯道的闭环赛道（或用种子矩形闭环），右侧"循迹控制"区打开循迹开关 → 画布出现小车轨迹线（闭环仅一圈）、当前车框、电感位置；拖动 Kp 滑块或修改误差公式文本 → 约 200ms 后轨迹、Err(t)/轮速(t) 曲线与结果摘要（状态/用时/弧长/步数）同步刷新，无需手动触发。
2. **公式编辑回退**：误差公式文本框输入非法表达式（如 `L1+`）→ 提示并回退默认公式，轨迹不发散、无 NaN；改回合法自定义式（如 `(L1-R1)/(L1+R1+1e-6)*P`）→ 轨迹按新公式重算。
3. **输入方式与钳位**：w / 轮距 W / dt / 电机τm / 初始 e / 初始 ψ 六项为数字直输（失焦/Enter 提交），越界值被钳位（如 W 输入 10 → 钳到 50 mm）；A/B/C/P/Kp/Kd/vBase/vMax/errLimit/errLimitSteps 滑块两端数值可点击改量程，自定义量程刷新页面后保留（appState `trackingRanges`）。
4. **电机滞后对照**：电机τm 设 0 → 起步轮速立即等于指令值（曲线无爬升段）；设 30 ms → 轮速(t) 曲线可见一阶爬升，过弯处实际差速滞后于指令。
5. **一键调 PID**：点"⚙ 一键调 PID"→ 按钮显示进度百分比（粗搜 13×11 + 邻域 9×9），期间 UI 可操作；结束后最优 Kp/Kd 自动填入并触发重算；调整按钮旁 Kp≤ / Kd≤ / 内收≤（默认 30 / 5 / 50mm）后重跑，结果随之变化。
6. **位姿来源切换**：车体位姿面板切到"跟随仿真轨迹"→ 轨迹进度滑块（上限 = 冲线点）驱动车体沿轨迹摆放，s/e/ψ 变为只读反算值；关闭循迹开关 → 该选项置灰提示并自动回退手动位姿；刷新后来源与进度保留。
7. **结果显示与导出**：全程扫描区切到"循迹轨迹电感值"图 → 各电感 U 曲线横轴可切 t / 弧长，竖线跟随轨迹进度；顶栏"导出"→ 循迹轨迹 CSV → 用 Excel 打开（BOM 兼容），表头列 `t(s),x(m),y(m),theta(rad),v_L(m/s),v_R(m/s),Err,L1_U(Vpp),…`，注释行含公式与全参数快照，行数 = 结果摘要步数。

## 回归检查

- **朝向约定**：`poseFrame` 的 ψ 符号约定（式 [(6.9)](../03-sensor-model/requirements.md#eq-6-9)，ψ = 切向角 − θ）不得再写反——V-7 专防；车框显示、位姿反算、TrackingSensorChart 取数共用该约定。
- **τ_m = 0 退化**：必须严格等价于 2026-08-12 前旧行为（轮速瞬时跟随指令），V-3 首项防护。
- **既有自检不破坏**：本功能改动后 `npm run selfcheck`（物理）与 `npm run selfcheck:measured`（实测模型）仍须全过；`scripts/test-appstate.ts`（含 v6 `trackingRanges` 字段）通过。
- **appState 兼容**：旧 v6 存档（无 motorTauMs）加载后循迹参数逐字段回退默认值，不崩溃、不丢其他状态（[`specs/techstack.md`](../../techstack.md) 硬性约束 3）。
- **终止判据语义**：闭环赛道仅一圈（不加 0.5m 容差）、非闭环总长 + 0.5m——V-6 防护；闭环吸合段几何属 `specs/features/01-track-geometry/`，其规约变更须同步复核 V-6。
- **读数来源注入**：`simulateTracking()` 不直接依赖场计算/实测模型实现，只经 `readSensor` 回调——切数据源（仿真 / 方案A / 方案B）后循迹读数与单点读数一致（通道无数据回退仿真并带 `*` 标注，见 `specs/features/04-measured-data-model/`）。
