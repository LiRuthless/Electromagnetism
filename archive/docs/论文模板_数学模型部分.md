# 学位论文写作模板（电磁 / 无线电能传输方向）

> 模板来源：精读四篇浙江大学电气工程博士学位论文归纳而成——
> 1. 卫璇《具有偏移兼容性的电场耦合式无线电能传输系统研究》
> 2. 姚艺翔《定频无线电能传输系统的偏移统一理论框架与线圈逆向设计理论》
> 3. 罗时英《感应式无线电能传输系统补偿拓扑设计研究》
> 4. 姚子睿《面向大功率无线电能传输系统的高偏移兼容性及弱耦合应用研究》
>
> 四篇论文骨架高度一致，说明这是该领域（建模仿真 + 电路/电磁分析 + 实验验证类）成熟、被评审认可的写作范式。**本模板重点在第 4～6 节：核心章节的数学模型部分。**

---

## 1. 论文总体骨架

```
前置部分
├─ 中文题名页 / 英文题名页
├─ 摘要 + 关键词（中文）
├─ ABSTRACT + Keywords（英文，与中文逐段对应）
├─ 目录 / 图目录 / 表目录
├─ 缩略语与符号表（可选，卫璇文中有 FHA 等缩略语表）
│
第 1 章 绪论
├─ 1.1 研究背景（课题背景 → 技术原理简介 → 国内外研究进展 → 课题的提出与意义）
├─ 1.2 面向××关键问题的研究现状（按 2～4 个关键技术分支分类综述）
└─ 1.3 本文主要研究内容（提炼关键科学问题 + 分点列出研究内容 + 全文结构框图）
│
第 2～N-1 章 核心章节（每章一个独立成果，结构完全同构，见第 4 节）
│
第 N 章 总结与展望
├─ N.1 论文工作总结（逐章对应总结）
└─ N.2 工作展望（3 条左右，承接本文不足）
│
参考文献
图表清单
攻读学位期间取得的成果
致谢
```

**核心章数量规律**：3～4 个核心章。章与章之间是"问题递进"关系，例如卫璇：恒压/恒流基础设计（第2章）→ 抗偏移参数设计（第3章）→ 偏移+负载双重兼容（第4章）；罗时英：恒定输出拓扑推导（第2章）→ 平衡设计方法（第3章）→ 宽负载低电流（第4章）→ 磁集成（第5章）。**每个核心章 = 解决一个明确的关键问题 + 提出一个方法 + 给出一个验证。**

## 2. 摘要的写法（五段式）

1. **领域大背景**（2～3 句）：领域价值。"无线电能传输技术的出现以及发展对人类的生活方式带来了新的选择与极大的便利。与传统接触式有线充电相比，无线电能传输具备……优势。"
2. **现有路线的问题 → 本文路线的优势**（2～3 句）："然而，IPT 技术存在着……等问题。××技术是一种……方式，与 IPT 相比具有……优点。"
3. **研究对象 + 核心问题**（1～2 句）："本文以……作为研究对象，主要对系统的……问题进行了研究。"
4. **研究内容分述**（"本文的主要研究内容主要分为以下×个部分：首先……其次……最后……"）——每部分固定句式：
   > **针对**……（应用场景/问题），**提出了**一种基于……（理论工具）的……方法/系统，**可实现**……（性能指标）。（方法要点：通过……推导/分析，给出……设计准则/流程。）**通过** ×kW 样机搭建与实验，**验证了**……有效性，系统具备……特点。
5. **关键词**：4～6 个，"领域对象；特性 1；特性 2；方法特征"。

英文摘要与中文逐段对应，首词对应 Firstly / Secondly / Finally。

## 3. 第 1 章 绪论的写法

- **1.1.1 技术原理**：给出系统组成示意图（图 1.x），逐模块一句话说明功能（直流源 → 逆变器 → 补偿网络 → 耦合机构 → 副边补偿 → 整流 → 负载）。
- **1.1.2 国内外研究进展**：按机构/团队时间线梳理（奥克兰大学 → KAIST → ORNL → 国内高校……），每条给出代表性指标（功率等级、效率、气隙），配装置图。
- **1.1.3 课题的提出与意义**：从应用需求反推技术指标矛盾，明确提出本文要解决的关键问题。
- **1.2 研究现状（按关键问题分类）**：每个分支一节，先给分类框架（"现有方法可分为三类：①……②……③……"），再逐类引文献评述，**每类末尾指出尚存的不足**——为本文内容埋下伏笔。
- **1.3 本文主要研究内容**：先用一段把关键问题凝练为科学问题；然后"针对上述问题，本文展开以下研究："分点列出（与核心章一一对应）；最后给"本文架构说明/全文结构框图"（图 1.x）。

## 4. 核心章节的通用结构（模板主体）

每个核心章严格同构，共 8 个标准件：

```
X.1 引言（章首语，见 4.1）
X.2 系统建模（数学模型第一部分，见第 5 节）★
X.3 特性分析 / 设计准则推导（数学模型第二部分，见第 6 节）★
X.4 参数设计方法与流程（含设计流程图）
X.5 仿真验证
X.6 实验验证（样机 + 波形 + 数据 + 效率）
X.7 与现有方法的比较（表格对比功率/效率/偏移范围/元件数）
X.8 本章小结
```

### 4.1 章首语（X.1 引言）的写法

一段式，固定逻辑链：**承接上文 → 提出问题 → 给出本章方法 → 预告本章安排**。

> "上一章/已有研究表明……，然而……问题尚未解决。针对这一问题，本章提出了一种基于……的……方法。首先，对……进行建模分析；然后，推导……的约束条件/设计准则；接着，给出参数设计方法与流程；最后通过仿真与实验验证所提方法的有效性。"

章末有时加一段"本章安排如下：X.2 节……；X.3 节……"。

### 4.2 X.4 参数设计方法

- 把第 X.3 节推导出的约束条件转化为**可执行的设计步骤**（第一步……第二步……），画**设计流程图**（图 X.x）。
- 明确哪些是自由量、哪些由约束方程确定（呼应"自由度分析"）。
- 给出**选取原则**：如不对称因数 τ 的取值范围、元件应力限制、谐振条件。

### 4.3 X.5 仿真验证

- 交代仿真工具与模型（"在 MATLAB/Simulink（或 ANSYS Maxwell / PLECS）中搭建……仿真模型"）。
- 仿真参数表（表 X.x）。
- 仿真曲线与理论曲线**同图对比**（验证推导的解析表达式）。
- 一句话结论："仿真结果与理论分析吻合，验证了……推导的正确性。"

### 4.4 X.6 实验验证

固定四件套：
1. **实验平台**：装置照片（图 X.x），说明逆变器/整流器器件型号、测量仪器（功率分析仪、示波器）。
2. **参数表**：实际样机参数（表 X.x：电感、电容、频率、功率等级……），与理论设计值并列。
3. **波形图**：逆变器输出电压/电流波形（验证 ZPA/ZVS），不同偏移/负载位置下的波形对比。
4. **数据曲线**：输出功率/效率—偏移（或负载）曲线，实验点与理论曲线同图；给出效率峰值与全范围效率数值。

### 4.5 X.7 与现有方法的比较

用一张表（表 X.x）与代表性文献系统横向对比：功率等级、开关频率、偏移兼容范围、负载范围、效率、元件数量、是否需要闭环控制。正文一句："与已有方法相比，所提系统在……方面具有优势。"

### 4.6 X.8 本章小结

一段式（或分点），镜像章首语："本章针对……问题，提出了……方法。首先……然后……最后……。仿真与实验结果表明，……。"

## 5. 数学模型部分·第一段：系统建模（X.2 节）★

这是四篇论文最规整、共性最强的部分，固定为 **七步链条**：

### 步骤 1：系统组成与电路结构描述（定性）

> "典型的××系统由发送端和接收端组成，如图 X.1 所示，包括直流电压源、逆变器、原边补偿网络、耦合机构、副边补偿网络、整流器和负载。"

随后 3～5 句逐模块说明能量流（直流→方波→谐振升压→耦合传输→整流→负载）。**先给系统结构图（图 X.1(a)），再给简化等效电路图（图 X.1(b)），两图一组。**

### 步骤 2：建模假设声明（必备，且要给理由）

标准三件套，缺一不可：

> "由于系统开关频率通常工作在谐振频率附近，在高品质因数下，谐振电路可视为带通滤波器，即仅开关频率次电流进行能量传输，高次谐波的影响忽略不计，故**基波分析法（Fundamental Harmonic Analysis, FHA）**[文献] 可用于对所提电路进行分析建模。为便于分析，**所有元器件均视为理想元器件**（忽略寄生电阻/寄生参数）。耦合机构采用**互感等效模型**。"

即：① 基波近似（理由：高 Q 带通特性）；② 理想元件（理由：寄生参数小，初步分析）；③ 耦合机构的等效模型选择（互感模型 / Π 型 / T 型）。

### 步骤 3：端口电气量定义 + 基本关系式（全文公式起点）

定义交流侧等效量，给出第一组公式：

$$U_{AB}=\frac{2\sqrt{2}}{\pi}V_{in},\qquad U_{CD}=\frac{2\sqrt{2}}{\pi}V_{out} \tag{X.1}$$

$$R_{ac}=\frac{8}{\pi^{2}}R_{L} \tag{X.2}$$

写法规范：先一句引导语"根据基波分析法，基波电压有效值可以表示为："，公式后用"其中，U_AB 和 U_CD 分别为全桥逆变器后和整流桥前的基波电压有效值，……"逐一解释符号。

### 步骤 4：耦合机构的电气建模

- 给出耦合机构结构示意图；说明建模思路（"每两个极板之间可形成一个等效耦合电容，因此四极板耦合器可构建为六个耦合电容的全耦合模型"）。
- **模型等效变换链条**：全耦合模型 → Π 型网络（自容 C_S1、C_S2、互容 C_M / 自感 L_p、L_s、互感 M）→ T 型网络，每个变换给出变换公式并引文献（"通过文献[x]中经典的星型-三角形等效变换公式可以直接计算……为："）。
- **定义关键无量纲参数**：耦合系数 k = C_M/√(C₁C₂) 或 k = M/√(L_pL_s)；等效自参数含外加补偿元件的归并（"若存在外部并联电容 C_ex1、C_ex2，则定义等效自电容……"）。

### 步骤 5：系统级方程（KVL / 回路电流 / 二端口矩阵，三选一或组合）

四篇论文的三种建模范式：

**范式 A：直接 KVL 方程组**（姚子睿、卫璇部分章节）
> "对于给定的开关角频率 ω，根据基尔霍夫定律，可以得到原边和副边耦合电压和电流之间的关系为："

$$\begin{cases}\dot U_{AB}=j\omega L_p\dot I_p+\dfrac{1}{j\omega C_p}\dot I_p+j\omega M\dot I_s\\[2mm] \dot U_{CD}=j\omega L_s\dot I_s+\dfrac{1}{j\omega C_s}\dot I_s+j\omega M\dot I_p\end{cases},\qquad M=k\sqrt{L_pL_s} \tag{X.3}$$

**范式 B：回路电流方程 + 阻抗矩阵**（姚艺翔，适合多回路/多线圈统一建模）
> "根据回路电流方程的列写规则[文献]，图 X.1 中的四种两线圈 WPT 系统的回路电流方程分别为："

$$\dot{\mathbf U}=\mathbf Z\,\dot{\mathbf I},\qquad \mathbf Z=\begin{bmatrix}\mathbf P & \mathbf M\\ \mathbf M^{T} & \mathbf S\end{bmatrix} \tag{X.4}$$

先逐个回路列写（式 X.4a~d），**再统一为矩阵形式**，并做分块（P 原边块、S 副边块、M 耦合块）——"统一模型"的写法：从最简单情形入手，逐级推广，最后给出一般形式。

**范式 C：二端口传输参数级联**（罗时英，适合补偿拓扑设计）
> "整体补偿拓扑可视为原边补偿网络、松耦合变压器和副边补偿网络三个二端口子网络的级联。定义三者的传输参数矩阵分别为 A₁、A_M 和 A₂……根据二端口网络的级联特性，整体传输参数矩阵为："

$$\mathbf A=\mathbf A_1\mathbf A_M\mathbf A_2 \tag{X.5}$$

并说明参数性质："由二端口的互易性，ad−bc=1；在线性无源 LC 网络中，a、d 为实数，b、c 为虚数。"——**这类"参数性质说明"是体现推导严谨性的标志性写法。**

### 步骤 6：理论工具引入（如使用专门工具）

若使用专门数学工具（回旋器/回转器理论、戴维南等效、镜像法），单独设小节：

> "回旋器理论是一种线性的无损转换二端口网络[文献]。……其输入输出特性可以表示为："（给矩阵方程）

先给定义与基本方程 → 再给关键性质（阻抗变换、级联合并）→ 最后一句点明"该特性对于实现与负载无关的恒压输出/零相角输入是非常重要的"——**性质后必跟一句物理意义。**

### 步骤 7：关键派生参数定义（为特性分析埋钩子）

在建模末尾定义全文将围绕其展开的设计参数，例如：

- 偏移系数：x = M_偏移/M_正对（"将偏移的影响归一化处理"）
- 不对称因数：τ_u = (U_CD/U_AB)·(L_p/L_s)、τ_c = ω_s/ω_p
- 谐振频率：ω_p = 1/√(L_pC_p)、ω_s = 1/√(L_sC_s)

> 句式："为了简化分析，引入不对称补偿因数 τ_c，其定义为：……其取值范围为 (0,+∞)，当原副边调谐至同一谐振频率时其值为 1。"

## 6. 数学模型部分·第二段：特性分析与设计准则（X.3 节）★

建模之后不是直接给结果，而是按固定推导链展开：

### 6.1 输出特性求解

> "由于副边整流桥的箝位作用，整流桥前电压 U_CD 与副边电流 I_s 相位相差 180°，**联立式（X.2）和式（X.3），可以得到系统输出功率特性为：**"

$$P_{out}=f(k,\omega,\tau,\dots) \tag{X.6}$$

要点：**交代求解所用的边界/约束条件**（整流器箝位、ZPA 条件等），说明"联立哪几式"得到结果。

### 6.2 输入阻抗与 ZPA/ZVS 分析

> "由式（X.3）可以进一步得到系统输入阻抗角 θ 的表达式为："（给表达式）

随后给物理解读："系统有功功率与原边电流和 cosθ 的乘积成正比，因此输入阻抗角可作为最小化逆变器电流的优化目标。"——**每个解析表达式后都配一段"电路分析表明/由式(X.x)可知"的物理解读。**

### 6.3 归一化与无量纲分析（本范式最鲜明的特征）

以姚艺翔的推导链为标杆：

1. 写出含绝对量的特性式 P(x)；
2. **施加设计条件**求参数关系："定义系统在正对位置处（x=1）和最大偏移位置处（x=x_min）的输出功率相同，那么……解出 x_min² = ……"；
3. **归一化**："将式（X.x）归一化至 x=1 处，可以得到归一化输出功率—偏移特性 p_R(x) = ……"；
4. **求极值**："对式（X.x）使用基本不等式，可以计算出 p_R(x) 的最大值……当且仅当 x = √x_min 时取等号"；
5. **定义性能指标系数**："将最大输出功率与正对位置输出功率之比定义为输出功率波动系数 κ_R(x_min, λ) = ……"。

即：**绝对量式 → 设计条件 → 归一化式 → 极值分析 → 定义波动/优值系数 → 特性曲线图**（理论曲线，图 X.x，横轴无量纲偏移系数 x）。

### 6.4 约束条件与分类讨论

- 对特性式做**零极点分析**："对式（X.x）进行求解，其零点和极点可以表示为：……当开关频率等于零点时，系统输出功率趋向于零；当等于极点时，输出增益趋向于无穷。"
- **分类讨论**："根据××的取值情况，零极点分布可分为四种情况：Case 1……Case 2……"每种 Case 一小节，配约束不等式与特性曲线图。
- **自由度分析**（可选，卫璇范式）：推导实现目标特性所需的最小自由度，进而确定最少元件数量："实现上述目标所需的自由度为 n，因此补偿网络至少需要 n 个独立元件。"

### 6.5 非理想因素影响分析（加分小节，可选）

姚子睿范式：在理想模型分析后，设小节讨论"考虑元件串联等效电阻影响""考虑元件容差影响""考虑高次谐波影响"——每个因素给出修正后的表达式或仿真对比，说明理想模型结论的适用边界。

## 7. 数学写作规范（从四篇论文提取的硬性惯例）

1. **公式编号**：按章编号 (2.1)、(2.2)……（或 (2-1) 式，全篇统一即可）；推导中被后续引用的式子必须编号。
2. **引导句式**（公式前必有引导语，以冒号收尾）：
   - "根据基尔霍夫定律，可以得到……为："
   - "根据基波分析法，交流电压有效值与直流电压关系为："
   - "……可计算为："／"……定义为："／"……可以表示为："
3. **符号说明**：公式后紧跟"其中，M 为松耦合变压器的互感，k 为耦合系数，……"，每个新符号首次出现必解释。
4. **推导衔接句式**：
   - "联立式（X.2）和式（X.3），可以得到……"
   - "将式（X.5）代入式（X.4），可得……"
