# Phase 5: 循迹闭环控制 — 实现计划

> 本规约为已实现功能的回溯文档化（棕地逆向，2026-09-30 依据归档设计文档补齐）。

## 目标

建立与实车控制代码一致的循迹闭环仿真：车体按两轮差速运动学行驶，轨迹完全由轮速积分决定；闭环信号流为"电感读数 → 可编辑误差公式 → PD → 差速轮速指令（w:1 分配、限幅）→ 电机一阶滞后 → 运动学积分新位姿"，用于赛前调参。配套提供参数调节界面（任一参数修改防抖 ~200ms 轨迹同步重算）、一键调 PID（轨迹形状贴合目标函数网格整定）、位姿来源切换、循迹结果显示与轨迹 CSV 导出（接口②）。

## 背景与依据

- 关联宪章：`specs/mission.md` 范围内条目"循迹闭环仿真：可编辑误差公式、PD、差速轮速、电机一阶滞后、运动学积分、一键整定"；成功标准"一键整定得到的 Kp/Kd 与整车参数（τ_m、W、v_base）经实验标定回填后可直接指导实车调参"。
- 技术约束（`specs/techstack.md`）：硬性约束 1（SI 单位内部计算，界面显示 mm / Vpp）；约束 2（`src/mathmodel/` 纯计算层，禁 UI 依赖）；约束 3（appState schema 纪律——本功能 motorTauMs 逐字段回退、未升版本即其先例）；约束 5（**表达式解析禁用 `eval`**，误差公式走递归下降解析 `compileFormula()`）。
- 前置条件：Phase 1 `01-track-geometry`（路径采样 `samplePath()`/`pointAtLength()`、闭环吸合、`createNearestSeeker()` 局部最近点查询）；Phase 2 `02-magnetic-field`（单点场 `computeB()`）；Phase 3 `03-sensor-model`（式 (6.1) 响应、车体位姿变换、式 (6.9) ψ 符号约定）；Phase 4 `04-measured-data-model`（实测数据源，`readSensor` 按当前数据源注入）。
- 参数性质：τ_m、W、v_base 等整车参数均为名义先验值，由实车实验标定回填（实验规程见 `specs/research/2026-08-13-experiment-modeling.md` 实验 4/5；数据接口见 `specs/features/07-persistence-export/` 接口③）。

## 风险与取舍

- **明确排除 `eval`**：误差表达式必须递归下降解析（`compileFormula()`），techstack 硬性约束 5，杜绝任意代码执行。
- **设计变更（2026-08-03，已落地）**：一键调 PID 目标函数由"最快完赛"改为"轨迹形状贴合"（直线贴中线、弯道内收圆润、外偏双倍罚、罚航向抖动）——最快完赛会奖励冲线式过弯，不符合驾驶经验；默认误差公式随默认 4 电感布局去 F1/F2。
- **τ_m = 0 退化**：2026-08-12 前的旧行为（轮速瞬时跟随指令）保留为 τ_m = 0 的退化情形，向后兼容，非独立方案。
- **分母零 / NaN 防护**：求值非法回退上一步误差而非报错中止，保证参数探索期（一键整定扫描极端组合）仿真不发散出 NaN。
- **主线程同步积分**：整条轨迹数百~数千步 × 每步电感数个单点场计算，毫秒级，无需 Worker；一键整定评价随网格搜索同步进行，分块 `setTimeout(0)` 让出事件循环保持 UI 响应。
- **控制律与实车代码一致**：不引入实车不具备的环节（本工具定位 = 赛前调参，见 `specs/mission.md` 范围外"实车嵌入式控制代码"）。
