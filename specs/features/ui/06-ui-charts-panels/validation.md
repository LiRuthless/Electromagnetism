## 自动化验证

在 `em-field-studio/` 下执行（截图依赖 dist，须先 build）：

```bash
npm run build
node_modules/.bin/electron.cmd scripts/ui/screenshot.cjs shots/ui-default.png   1600 950 default
node_modules/.bin/electron.cmd scripts/ui/screenshot.cjs shots/ui-measured.png  1600 950 measured
node_modules/.bin/electron.cmd scripts/ui/screenshot.cjs shots/ui-collapsed.png 1600 950 default collapse
node_modules/.bin/electron.cmd scripts/ui/screenshot.cjs shots/ui-narrow.png    1280 800 default
```

判据：

- `npm run build` 退出码 0；
- 四张 PNG 均生成，逐一目检：
  - `ui-default.png`（默认布局 + 演示矩形闭环赛道）：三栏完整、图表就位、无溢出；
  - `ui-measured.png`（数据源切最长选项"实测物理+偏差 · 方案B"）：Select 触发框省略号截断、不撑破面板；
  - `ui-collapsed.png`（双栏收起）：左右均为 32px 窄条，画布占满中部；
  - `ui-narrow.png`（窄窗口 1280×800）：无横向挤压溢出、面板可调可用。

已知限制：screenshot.cjs 以固定延时（6 s）等待场计算完成，慢机器上若截到计算中画面须复跑；截图为目检辅助，不构成自动断言。

## 人工验证步骤

`npm run dev`（或预览 dist）后逐项操作：

### 缩放（V-3）

1. 在"全程扫描 U(s)"图上按住左键框选一段区间 → 放大到该区间，y 量程随可见数据拉伸；
2. 滚轮上滚/下滚 → 以光标为中心放大/缩小；
3. 按住 Shift 拖拽（或中键拖拽）→ 平移可见窗口；
4. 双击图面或点右上角"⟲ 复位" → 回全量程；放大后悬停 tooltip 仍可用；
5. 切到双图 Tab②"循迹轨迹电感值"再切回 → ①的缩放状态保留（hidden 挂载）；
6. 同样操作 Err(t)/轮速(t)（TrackingPanel 内）与实测对比预览图（recharts，按可见域过滤）。

### 浮动（V-4）

1. 按住"全程扫描"图标题栏拖入中央画布 → 进入画布区域即转为浮动窗（拖出阈值）并继续拖动；或点标题栏"⧉"直接浮出于画布中央（默认 420×280）；
2. 拖浮动窗标题栏 → 画布范围内任意移动，拖不出画布边界；
3. 拖边框/四角八个方向拉伸 → 尺寸随之变化，最小钳位 240×160，图表内容随尺寸重排；
4. 浮动窗内执行 V-3 缩放与 V-5 点击联动 → 均可用；
5. 多浮出几张图，交替点按 → 最近操作的在上（z 序）；
6. 点"收回" → 图回原面板位置，原位占位条消失，缩放域重置（浮出瞬间亦重置）；
7. 刷新页面 → 浮动状态（是否浮出/位置/尺寸）恢复（appState v6 `floatingCharts`）；
8. 循迹未开启时浮出循迹类图 → 空态提示。

### 点击联动（V-5）

1. 点击全程扫描图某数据点 → 位姿来源切"手动位姿"，s 滑块跳到该点弧长，画布车框、读数剖面图、扫描竖线同步；
2. 开启循迹后点击循迹轨迹电感图 / Err(t) / 轮速(t) 某数据点 → 位姿来源切"跟随仿真轨迹"，trajT 定位到该时间步，车体摆上对应位姿；
3. 循迹未开启时点击循迹类图 → 提示"循迹无有效轨迹"，位姿不变；
4. 点击读数剖面图 → 无任何联动；
5. 在图上做微小框选（< 2% 图宽）→ 视为单击触发联动而非缩放；正常框选不触发联动。

### 面板调宽与收起（V-6）

1. 拖左面板右缘 → 240px–45% 窗口宽内连续可调；继续往最小拖 → 自动收起为 32px 窄条；右面板同理（300px–55%）；画布始终 ≥30%；
2. 点窄条展开按钮恢复；
3. 刷新页面 → 面板宽度布局恢复（`panel-layout` key）；左栏收起状态恢复、右栏收起不恢复（会话内）；
4. 面板滚到底 → 顶部粘性标题栏（"赛道编辑"/"电感与仿真"）保持可见。

### 分区卡片与键入（V-7）

1. 点分区标题栏 → 折叠/展开，chevron 旋转；点标题栏右侧按钮（如电感布局"添加"）→ 不触发折叠；
2. 默认折叠检查：左侧"计算状态"、右侧"物理公式"默认收起；"实测数据标定"未导入数据时默认收起、选中实测源或已导入后默认展开；
3. 点击 s/e/ψ 或标定 Vpp 的当前数值 → 键入精确值，Enter/失焦提交，越界值钳位到滑块量程；
4. 刷新页面 → 分区折叠状态不恢复（会话内）。

## 回归检查

本功能不得破坏的既有行为：

- `npm run selfcheck` / `npm run selfcheck:measured` / `npm run selfcheck:tracking` 三组自检全部通过（本功能不改 `src/model/`，物理结果不得漂移）；
- `scripts/test-*.ts` 附加测试（含 appState v6 `floatingCharts` 持久化、状态恢复）通过；
- 画布铺设交互（直线/圆弧/形状工具、闭环勾选）与转角刻度叠加不受影响（规格见 `specs/features/model/01-track-geometry/`）；
- 顶栏导出菜单六项导出均可用（格式见 `specs/features/ui/07-persistence-export/`）；
- 位姿来源切换（手动/跟随轨迹）与循迹参数修改后轨迹自动重算不受影响（规格见 `specs/features/model/05-tracking-control/`）；
- 旧 v6 存档无损加载：`panel-layout` 损坏/缺失只回退默认面板宽度，不丢工作状态，启动绝不崩溃。
