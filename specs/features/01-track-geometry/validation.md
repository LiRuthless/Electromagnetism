## 自动化验证

在 `em-field-studio/` 下执行：

```bash
npm run selfcheck                 # 主验证：前置 400 段检查 + [3][4][6] 全过
npm run selfcheck:tracking        # [5] 闭环几何项全过
npx tsx scripts/test-corner.ts    # 尖角 L 形赛道误差表
npm run build                     # 类型检查 + 构建 dist 通过
```

判据：两条 selfcheck 命令 exit 0（输出"全部自检通过 ✓"，无 FAIL 行）；`test-corner.ts` 汇总行"新闭式引擎：最大误差"为双精度机器量级（约 1e-9 以下）；`npm run build` 无错误。

## 人工验证步骤

启动：`cd em-field-studio && npm run dev`（或静态预览 dist 构建产物）。

1. **直线连线铺设**：左侧 TrackEditor 保持 Tab"鼠标铺设"→ 子模式"直线连线"，在画布单击逐点连线。
   预期：顶点吸附 10 mm；键入数字可锁定长度/角度（CAD 风格动态输入，Tab 切换输入框）；双击 / Esc 结束后状态变为"○ 已结束（单击画布继续）"；切到 Tab"段列表查看"可见逐段"#n 直线 ℓmm ∠θ°"且为只读。
2. **圆弧段铺设**：子模式切"圆弧段"，拖半径滑块（50–2000 mm，10 mm 步进），圆心角点 90° 按钮（或输入 1–360°），选左/右转。
   预期：画布显示虚影预览；点"铺设该圆弧"后新段沿当前切线接续；段列表出现"#n 圆弧 R…mm 90°右 弧长…mm"。
3. **形状工具**：设直角弯边长 300 mm 点"右转90°"；设正六边形边长 500 mm、右环，点"生成环岛"。
   预期：直角弯新增一段带 ∠ 标注的直线段（尖角转向）；环岛新增 6 段直线、赛道总长增加 3000 mm，笔尖回到入环顶点且航向不变，继续铺直线自然出环（"直线—顶点—绕环—顶点—直线"）。
4. **闭环勾选**：用直线连线铺近似方形回到起点附近。
   预期：闭环开关旁实时显示"终点距起点 X mm"；X ≤ 20 mm 时可勾选，勾选后赛道总长含吸合段、提示"闭环后自动吸合；循迹仿真仅生成一圈轨迹"；X > 20 mm 时开关置灰并提示无法闭环；勾选后"撤销一段"使缝隙超阈值 → 闭环自动取消（开关回到关）。
5. **转角刻度**：画布右下角"转角刻度"开关（默认开）。
   预期：每个转角顶点两侧各一条标称 300 mm 标尺（带 100 mm 分度 tick 与端点标注）；直角弯处两侧标尺互相垂直；相接段 < 300 mm 的侧只画到段端；环岛各顶点有标尺；含圆弧段的赛道仅在段间接缝顶点标注，圆弧侧为沿顶点切线的直标尺；关闭开关标尺全部消失；缩放/平移视图时标尺随赛道联动、不遮挡段长数字；刷新页面后开关恢复默认开（不持久化）。
6. **赛道库与 JSON**：输入名称点"保存当前"；对该条目改名、载入、删除；"导出赛道 JSON"后"清空重铺"，再"导入赛道 JSON"。
   预期：列表条目显示名称、总长与保存日期；改名/载入/删除生效；导入后恢复原赛道；闭环赛道导出的 JSON 含 `closed: true`，导入后闭环仍生效；点顶栏"恢复默认"后赛道库条目仍在。
7. **撤销/清空、段长标注、计算状态**：开"显示每段长度标注"；逐次"撤销一段"后"清空重铺"；查看"计算状态"分区。
   预期：画布各段中点处显示段长 mm 数字、关闭即隐藏；撤销移除末段、清空后段数为 0；计算状态显示离散电流元段数、网格单元数（上限 160k，超出时提示已自动降档）、赛道总长、上次重算耗时，数值随铺设实时更新。
