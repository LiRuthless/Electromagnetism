# Phase 2: 磁场计算与网格调度 — 实现计划

> 本规约为已实现功能的回溯文档化（棕地逆向，2026-09-30 依据归档设计文档补齐）。

## 目标

对贴地载流赛道（20 kHz / 100 mA）在观测平面 z = h 上建立精确且可交互的磁场计算能力：毕奥-萨伐尔分段积分 + 直线段闭式解 + 奇异截断 + 解析对照解（式 (5.1)–(5.5)），观测面网格批算经 Web Worker 分块调度（防抖 / 协作式取消 / 看门狗 / 主线程兜底），保证大网格下 UI 不卡死、场必出图。

## 风险与取舍

- **直线段闭式解 vs 全部离散**：选择直线段不离散、直接闭式积分（精确，自检 [9] 达双精度机器量级 ~10⁻¹⁴），仅圆弧段保持 ≤ 1 cm 离散（离散积分相对闭式解误差 < 0.1%）；明确排除"全部段按 1 cm 离散"方案——直线段离散只会无谓引入误差。
- **网格计算放 Web Worker 而非主线程**：大网格（上限 160k 单元 × 数百电流元）主线程同步计算会卡死 UI；代价是必须配套协作式取消、看门狗与主线程兜底链路。取舍原则：宁可降级慢算，也要保证场必出图。
- **奇异截断的物理含义**：R_MIN = 1 mm 等效于给细线电流一个 1 mm 量级的有限半径，在 ≥ 2 cm 探测距离处对场值的影响可忽略（与假设 2 的 0.5 mm 真实线径不矛盾——截断是数值保护，不是物理建模）。
- **准静态近似的边界**：20 kHz 电磁波波长约 15 km ≫ cm 级探测尺度，位移电流与辐射效应可忽略；明确排除三维 / 瞬态 / 全波电磁场仿真（mission 范围外）。假设的实车适用边界由实验建模回环标定（见 validation.md 假设回环小节）。
- **Worker 结果分量裁剪**：画布热力图只需 Bx / Bz / |B|，`computeGrid` 不输出 By（省 1/4 内存与传输量）；By 仅 `computeGridFull` 输出（CSV 导出用，见 `specs/features/07-persistence-export/`）。
