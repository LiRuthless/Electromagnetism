# 智能车竞赛电磁组赛道建模方案

> 版本：v1.0 ｜ 用途：电磁循迹智能车控制算法的理论建模与仿真验证
> 目标读者：电磁组队员（硬件 / 控制算法方向）

---

## 1. 建模目标

回答一个核心问题：**车在任意横向偏差、任意高度、任意赛道几何下，每个电感的 ADC 读数是多少？**

建模的三个直接用途：

| # | 用途 | 对应的控制算法环节 |
|---|------|-------------------|
| 1 | 确定 error 信号的计算方式与线性区 | PID 输入归一化 |
| 2 | 确定电感布局（高度、间距、倾角、前瞻距离） | 硬件安装决策 |
| 3 | 推导弯道 / 十字 / 环岛等元素的信号特征 | 元素识别判据 |

---

## 2. 建模对象与基本假设

### 2.1 赛道电磁线参数（以竞赛规则为准，建模前核实）

- 交变电流：20 kHz，约 100 mA
- 导线直径 << 传感器探测距离，视为**无限细线电流**
- 铜管/漆包线贴地铺设

### 2.2 简化假设

1. **准静态近似**：20 kHz 波长 15 km >> 探测尺度（cm 级），按静磁场处理，忽略电磁传播效应。
2. 忽略趋肤效应、临近金属涡流、地磁影响（量级 < 1%）。
3. 电感线圈视为理想点探头，敏感轴方向明确，无交叉灵敏度。

> 上述假设带来的误差统一在**实测标定**阶段用修正系数吸收（见第 6 节）。

## 3. 物理模型：电磁线磁场

### 3.1 直道段：无限长直导线近似

$$B(r) = \frac{\mu_0 I}{2\pi r}$$

- B 随到导线的垂直距离 r **反比衰减**
- 方向沿环绕导线的切向（右手定则）
- 有效探测范围实测约 ±20~25 cm，超出后信噪比急剧恶化

### 3.2 一般赛道：毕奥-萨伐尔定律分段积分

$$d\vec{B} = \frac{\mu_0 I}{4\pi} \frac{I\,d\vec{l} \times \vec{r}}{r^3}$$

**赛道几何参数化**：把赛道中线拆成基本段序列

| 段类型 | 参数 | 备注 |
|--------|------|------|
| 直线段 | 起点、方向、长度 | 解析解可直接用 |
| 圆弧段 | 圆心、半径、起止角 | 弯道、环岛主体 |
| 回旋/过渡段 | 回旋线参数（可选） | 精确建模时可选，初版可用多段圆弧逼近 |

数值实现：每段离散为 N 个小段（段长 ≤ 1 cm），逐段累加 dB，得到空间任意点的 B 场矢量。

### 3.3 场量分解

对每个场点 P = (x, y, z)，输出：

- 竖直分量 Bz → 水平放置电感的主信号
- 水平横向分量 Bx → 竖直放置电感的主信号
- 合成幅值 |B| → 丢线判定 / 信号强度监测

## 4. 传感器模型：工字电感响应

### 4.1 单电感响应公式

$$U_i = k \cdot f \cdot \vec{B}(P_i) \cdot \hat{n}_i$$

- k：综合系数（匝数、截面积、放大电路增益），**标定确定**
- f：20 kHz（常数，并入 k）
- Pᵢ：第 i 个电感的位置（车体坐标系）
- n̂ᵢ：第 i 个电感的敏感轴单位向量（由安装倾角决定）

### 4.2 典型电感布局（建模参数表）

| 电感 | 安装方式 | 敏感轴 | 主要用途 |
|------|----------|--------|----------|
| L1 / R1 | 水平，横向对称分布于车头 | 竖直 (z) | 横向偏差主信号 |
| L2 / R2 | 水平，横向更宽或更前 | 竖直 (z) | 扩展探测范围 / 丢线判断 |
| M1 | 竖直，车头正中 | 水平横向 (x) | 过线检测、弯道特征 |
| F1 / F2 | 水平斜置"八字"，前瞻 20~40 cm | 竖直 (z) | 弯道预判 |

> 具体数量按本队车模实际布局填表，全部进入仿真参数文件。

### 4.3 车体位姿参数（建模输入）

- 横向偏差 e：车中心偏离导线的横向距离
- 航向角 ψ：车头方向与赛道切向的夹角
- 电感安装高度 h：距赛道平面
- 前瞻距离 d：前瞻电感到车头的纵向距离

## 5. 仿真方案（Python 实现）

### 5.1 代码结构

```
track_model/
├── track.py        # 赛道几何：直线/圆弧段定义，折线离散化
├── field.py        # 毕奥-萨伐尔积分，场点 B 场计算
├── sensor.py       # 电感布局表 + 响应公式 + 车体坐标变换
├── scenarios.py    # 仿真场景：直道扫描、弯道、十字、环岛
├── plots.py        # 场分布图、响应曲线、特征波形
└── calib.py        # 实测数据拟合修正
```

### 5.2 仿真场景清单（按优先级）

| 优先级 | 场景 | 扫描变量 | 输出 |
|--------|------|----------|------|
| P0 | 直道横向扫描 | e ∈ [−25, +25] cm，步长 1 cm | 各电感 U(e) 曲线；归一化差值 (L−R)/(L+R) 曲线及线性区 |
| P0 | 高度衰减 | h ∈ [2, 12] cm | U(h) 曲线 → 安装高度与丢线阈值 |
| P1 | 弯道（R = 50/80/120 cm） | e、ψ | 竖直电感特征波形 → 弯道判据 |
| P1 | 前瞻电感对比 | d ∈ [20, 40] cm | 不同前瞻距离下弯道信号提前量 |
| P2 | 十字交叉 | 过十字全过程 | 信号突变特征 → 十字判据 |
| P2 | 环岛入环点 | 入环轨迹 | 入环特征波形 |
| P3 | 坡道 | 车俯仰角 | h 变化对信号的影响 |

### 5.3 关键输出图

1. **B 场等值线俯视图**（直道 + 弯道）——直观理解场分布
2. **U(e) 响应曲线族**——各电感随横向偏差的响应
3. **归一化差值曲线**——PID 输入的线性度评估（目标：±15 cm 内近似线性）
4. **特征波形图**——元素识别判据的理论依据

## 6. 实测标定方案

模型是近似的，必须用实车数据修正。标定步骤：

1. **标定场搭建**：一段 3~5 m 直道，铺导线，通标准信号源。
2. **静态采集**：把车固定于已知偏差位置（e = −20, −15, …, +20 cm），记录各电感 ADC 值，每点采 50 次取均值。
3. **参数拟合**：以仿真 U(e) 曲线形状为基，拟合综合系数 k、安装倾角残差、等效高度残差。
4. **修正模型**：将拟合参数写回 `sensor.py`，重新生成理论曲线。
5. **交叉验证**：换一条弯道路段，对比修正模型预测 vs 实测，误差 < 10% 视为模型可用。

> 标定数据用 Excel 记录（时间 / 位置 / 各通道 ADC / 备注），可直接用 Python pandas 读入拟合。

## 附：常用公式速查

- 无限长直导线：B = μ₀I / (2πr)，μ₀ = 4π×10⁻⁷ H/m
- 毕奥-萨伐尔：d**B** = (μ₀/4π) · I d**l** × **r̂** / r²
- 电感响应：U = k · **B** · **n̂**
- 归一化偏差：err = (U_L − U_R) / (U_L + U_R)
